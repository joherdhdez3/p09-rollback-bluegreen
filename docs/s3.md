# AWS Simple Storage Service (S3)

En esta sección se realizarán los siguientes pasos:

- Crear el bucket de S3
- Bloquear el acceso público
- Verificar el bucket

El bucket almacenará el artefacto de despliegue (archivos del repositorio comprimidos) que el agente de CodeDeploy descarga en la instancia EC2.

**Variables utilizadas**

```bash
AWS_REGION="us-east-1"

S3_BUCKET="mi-app-codedeploy-NOMBRE-UNICO"
```

> El nombre del bucket debe ser único a nivel global en AWS. Se recomienda incluir tu ID de cuenta o un sufijo aleatorio, por ejemplo: `mi-app-codedeploy-123456789012`.

1. Crear el bucket

    ```bash
    aws s3 mb s3://$S3_BUCKET --region $AWS_REGION
    ```

    Resultado esperado:

    ```text
    make_bucket: mi-app-codedeploy-NOMBRE-UNICO
    ```

2. Bloquear el acceso público

    El bucket no debe ser accesible públicamente ya que solo lo utiliza el agente de CodeDeploy.

    ```bash
    aws s3api put-public-access-block \
        --bucket $S3_BUCKET \
        --public-access-block-configuration \
        "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"
    ```

3. Verificar el bucket

    ```bash
    aws s3 ls | grep $S3_BUCKET
    ```

    Resultado esperado:

    ```text
    YYYY-MM-DD HH:MM:SS mi-app-codedeploy-NOMBRE-UNICO
    ```

    Verificar la configuración de acceso público:

    ```bash
    aws s3api get-public-access-block --bucket $S3_BUCKET
    ```

    Resultado esperado:

    ```json
    {
        "PublicAccessBlockConfiguration": {
            "BlockPublicAcls": true,
            "IgnorePublicAcls": true,
            "BlockPublicPolicy": true,
            "RestrictPublicBuckets": true
        }
    }
    ```

4. Resultado esperado

    | Recurso | Configuración |
    |---|---|
    | Bucket | `mi-app-codedeploy-NOMBRE-UNICO` |
    | Región | `us-east-1` |
    | Acceso público | Bloqueado |
